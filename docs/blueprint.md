# **App Name**: MathMog

## Core Features:

- Problem Display: Display math problems based on selected difficulty and level.
- Answer Input: Allow users to input answers via text input or button selection.
- Feedback System: Provide instant feedback on answers, with explanations.
- Score Tracking: Keep track of user score (correct/total) and display it.
- Problem Generation: Generate different types of math problems dynamically based on user level and difficulty.
- Adaptive Difficulty: Based on a record of the user's recent performance, recommend an appropriate level of difficulty and skill for practice. If user performance indicates topic mastery, present a choice to increase the difficulty and level of math problems shown. This tool adapts to user proficiency, ensuring a challenging and rewarding learning experience.
- Study Guide: Allow users to study key concepts and tips to help them master mental math

## Style Guidelines:

- Primary color: Slate blue (#7395AE), evoking focus and intellect.
- Background color: Light gray (#EEEEEE), providing a clean and unobtrusive backdrop.
- Accent color: Warm terracotta (#BD7A59), used for highlights and interactive elements to draw attention.
- Body and headline font: 'PT Sans' sans-serif for clarity and readability.
- Use simple, geometric icons for navigation and problem categories.
- Maintain a clean and structured layout with clear visual hierarchy. Prioritize essential information.
- Incorporate subtle transitions and feedback animations to enhance user interaction and engagement.
